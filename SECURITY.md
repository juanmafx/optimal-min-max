# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Unversioned 2019 script | No |

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Open a GitHub issue that asks for a private contact channel and includes only a general description.

This is a personal study project, so no response time is guaranteed.

## Scope

The tool processes local standard input and command-line arguments. It has no network, authentication, or runtime file access. Its pseudorandom generator is not suitable for security-sensitive use.
